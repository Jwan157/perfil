# Jwanm — mejora visual V4

Esta versión conserva el proyecto original: PostgreSQL, Express, sesiones, Discord OAuth,
área privada, vistas, registro de visitas, audio, imágenes y opciones existentes.

Cambios visuales:
- Glassmorphism premium.
- Fondo cinematográfico con profundidad.
- Barra de estado JWNM.
- Reloj discreto.
- Iluminación que sigue el cursor en PC.
- Ripple en botones.
- Transiciones de paneles.
- Barra de progreso al recorrer el panel privado.
- Modal y tarjetas con profundidad.
- Responsive móvil.
- Accesibilidad básica con teclado.
- `prefers-reduced-motion`.

También se corrigió únicamente un token numérico accidental (`2308`) dentro del JavaScript
original que impedía ejecutar correctamente una parte del menú privado. No se eliminaron opciones.
